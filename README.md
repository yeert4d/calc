# Calculator (Early web project):

---

A sinmple calculator app built using vanilla HTML, CSS, and javascript.

---

This project was ccreated as an early learning exercise to understand:
  - DOM manipulation;
  - Event handling in JS;
  - Basic UI layout using CSS Grid;
  - Seperating structure (HTML), logic (JS), and styling (CSS);

---

## Features:
  - Basic arithmetic operations;
  - Button-based input;
  - Error handling for invalid expressions;

---
  
## Technical Notes:
  - This project intentionally avoids frameworks;
  - "eval" is used for simplicity in an early-stage project. In production a proper expression 
  parser would be preferable

---

## Status
This is an archieved learning project. More advanced work can be found in newer repositaries.
